# Lecture 01 GitHub Remote Demo Repo

This repository is prepared for Lecture 1 of the Big Binary Tech DevOps program.

It is designed for live classroom demos of:

- `git init`
- `git status`
- `git add`
- `git commit`
- `git branch`
- `git switch`
- `git remote add origin`
- `git push -u origin main`
- `git clone`
- `git pull`

## Demo purpose

Students should see how a simple local repository becomes a remote GitHub repository and how a branch-based workflow fits into normal team collaboration.

## Simple structure

- `README.md` for project overview
- `notes/session-summary.md` for class notes and branch demo edits
- `.gitignore` for basic cleanup
- `REMOTE-GITHUB-DEMO-COMMANDS.md` for the full live-teaching command sequence
